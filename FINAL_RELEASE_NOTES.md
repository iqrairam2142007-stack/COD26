# COD26 Final Release Notes

This is the final packaged version of the COD26 website project.

## Included in this final version
- Student login and account creation
- Direct student flow with transaction ID based access unlocking
- Partner school / college student flow with school code and student ID
- Admin dashboard with school code creation
- Admin access to topics, assignments, tests / arena, projects, payments, reminders, and certificate section
- Detailed Python learning units
- Theory, code example, AI lesson, and practice tabs in each unit
- In-app AI lesson player with:
  - clickable play / pause
  - replay
  - scene-by-scene lesson flow
  - progress bar
  - voice bot headline reading limit
- Python chatbot for topic-related questions
- Assignment PDF download
- Assignment submission per unit
- Project submission
- Admin review and approval system for assignments and projects
- Student dashboard review summary
- Certificate print / download flow after eligibility
- Deployment-ready files for Netlify and Vercel
- VS Code + Chrome guide
- Deployment guide

- `README.md`
